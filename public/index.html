## live demo — what's my car worth?

    
The app's similarity rule, running in your browser: same trim + same year + mileage ±15% + same damage group. When there aren't enough matches, the rule is relaxed step by step — and the result tells you what was relaxed.

## how it works


┌───────────────┐      ┌───────────────────────┐      ┌─────────────────┐      ┌──────────────────┐
│ [01] criteria │      │  [02] apify (parallel) │      │ [03] normalize  │      │  [04] decide     │
│ make / model  │ ───▶ │  ├─ sahibinden.com    │ ───▶ │ ₺ · km · year   │ ───▶ │ median · p25–p75 │
│ year · km     │      │  └─ arabam.com        │      │ damage · dedup  │      │ buy / sell range │
│ damage · city │      │   3 retries → backup  │      │ privacy filter  │      │ 3% price alerts  │
└───────────────┘      └───────────────────────┘      └─────────────────┘      └──────────────────┘
                                   │
                                   └── same query within 24h → cache (cost: 0)

      

        
[01] pick your criteria
Make → model → trim, year, mileage, damage, city. Or start from presets like “diesel sedans, 2018+”.

        
[02] two marketplaces, in parallel
sahibinden.com and arabam.com listings are collected through Apify. If a scraper fails: 3 retries, then a backup scraper.

        
[03] make the call
Median, price band, same-year ±10% km median and a buy (−5%) / sell (+5%) range — on one screen.

market_search
Price histogram and a mileage-vs-price scatter plot with damaged cars highlighted, plus a sortable, source-tagged listing table.

Enter year, mileage and damage; get a buy–sell range from comparable listings and an estimated time on market.

Photos, a panel-by-panel paint / spot-paint / replaced record, insurance claims, purchase and target price.

      

      


  store.url
     └─▶ [garage]

Paste your dealer storefront URL and your live listings become garage drafts — you approve each one. No password, ever.

      

      


  median Δ ≥ 3%
     └─▶ [!] alert

        
price_alerts
Follow a search; it's re-checked daily in a cheap summary mode and you're notified when the median moves.

  24h cache

        
cost_guard
Per-site listing caps, a 24-hour cache, a monthly budget threshold and admin approval before going over.

## privacy & trust


[✓] seller phone numbers and names are never stored (KVKK — Turkey's data protection law)
[✓] we never ask for your sahibinden / arabam password — linking = your storefront URL
[✓] listing text and photos are never republished — internal analysis only
[✓] every analysis is attributed: “Data: sahibinden.com & arabam.com via Apify”
