## canlı demo — bu araç kaç para?

    
Uygulamadaki benzerlik kuralı, tarayıcında: aynı versiyon + aynı yıl + km ±%15 + aynı hasar grubu. Yetersiz örnekte kural sırayla gevşetilir ve söylenir.

    

      
~/galeri_piyasa — bashdemo veri yükleniyor…

      

        
galerici@piyasa:~$ bu_arac_kac_para

        

          
          
          
          
        

        
      

      

    

    
Veri: uygulamanın demo modu (MOCK) — gerçek ilanlar değildir. Canlı modda aynı hesap sahibinden + arabam ilanlarıyla yapılır.

  


  
  

    

      
## nasıl çalışır


┌──────────────┐      ┌───────────────────────┐      ┌────────────────┐      ┌──────────────────┐
│  [01] kriter │      │  [02] apify (paralel)  │      │ [03] normalize │      │  [04] karar      │
│ marka/model  │ ───▶ │  ├─ sahibinden.com    │ ───▶ │ TL · km · yıl  │ ───▶ │ medyan · p25–p75 │
│ yıl · km     │      │  └─ arabam.com        │      │ hasar · dedup  │      │ kaç para aralığı │
│ hasar · şehir│      │   3 deneme → yedek    │      │ KVKK filtresi  │      │ fiyat alarmı %3  │
└──────────────┘      └───────────────────────┘      └────────────────┘      └──────────────────┘
                                  │
                                  └── aynı sorgu 24 saat içinde → önbellek (maliyet: 0)

      

        
[01] kriter seç
Marka → model → versiyon, yıl, km, hasar, şehir. Hazır şablonlar: “Dizel 2018+ sedanlar”.

        
[02] iki site paralel
sahibinden ve arabam ilanları Apify ile toplanır; actor çökerse 3 deneme, sonra yedek actor.

        
[03] karar ver
Medyan, bant, aynı yıl ±%10 km medyanı ve %5 altı alış / %5 üstü satış aralığı tek ekranda.

      

    

  


  
  

    
## özellikler

    

      


  ▁▃▅▇█▇▅▃▁
  p25 ┊ p75

        
piyasa_ara
Fiyat histogramı ve km–fiyat serpme grafiği; hasarlı ilanlar ayrı renkte, kaynak etiketli ilan listesi.

      

      


  [?] → ███ ₺
  ±%5 al/sat

        
bu_arac_kac_para
Yıl + km + hasar gir; benzer ilanlara göre alış–satış aralığı ve tahmini ilan süresi.

      

      


  ┌─┬─┬─┐ kaput
  │B│D│O│ tampon

        
garajim
Fotoğraf, parça parça boya / lokal boya / değişen kaydı, tramer, alış ve hedef fiyat.

      

      


  mağaza.url
     └─▶ [garaj]

        
magazamdan_getir
Mağaza profil adresini gir; açık ilanların onaylı olarak garaja aktarılsın. Şifre istenmez.

      

      


  medyan Δ ≥ %3
     └─▶ [!] bildirim

        
fiyat_alarmi
Aramayı takibe al; her gün ucuz özet modda yeniden hesaplanır, medyan oynarsa haber verir.

      

      


  $ ▮▮▮▮▮▯▯▯ bütçe
  24s önbellek

        
maliyet_korumasi
Site başına ilan tavanı, 24 saat önbellek, aylık bütçe eşiği ve yönetici onayı.
